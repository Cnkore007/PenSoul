# 作品库支持中文项目名

## 任务目标

作品库创建项目时支持中文名称：名称可输入中文，项目 ID 自动生成英文，列表与侧边栏显示中文标题。

## 关键决策与取舍

- 项目 ID 保持只允许字母、数字、下划线、连字符（磁盘目录与 URL 标识的安全边界），中文只作为标题存储。
- 自动生成 ID 优先提取名称中的英文/数字片段（如「移山 yishan」→ `yishan`）；纯中文回退为 `project-<时间戳+随机>`，不引入拼音依赖。
- 后端列表接口从仅返回 ID 改为返回 `ProjectSummary { project_id, title }`，读取时只解析 JSON 的 `title` 字段，不为列表加载整个本体。

## 改动文件清单

- `crates/pensoul-infra/src/persistence/project.rs`：新增 `ProjectSummary`，`list_projects` 返回中文标题；新增单元测试。
- `crates/pensoul-app/tests/api.rs`：新增列表返回中文标题的集成测试。
- `src/types.ts`：新增 `ProjectSummary` 类型。
- `src/ipc.ts`：`listProjects` 返回 `ProjectSummary[]`。
- `src/views/ProjectsView.tsx`：输入框改为「项目名称（支持中文）」，自动生成 ID，列表与删除确认显示中文标题。
- `src/App.tsx`、`src/components/Sidebar.tsx`：当前项目状态记录 ID + 标题，侧边栏显示中文标题。

## 验证结果

- `cargo test -p pensoul-infra -p pensoul-app`：全部通过（含新增测试）。
- `npx tsc --noEmit`：无类型错误。
- 接口实测：创建 `title=移山` 后 `GET /api/projects` 返回 `[{"project_id":"project-t1a2b3","title":"移山"}]`；测试项目已删除，数据目录无残留。
- 后端已重启（新二进制运行中），前端由 vite 热更新。

## 遗留事项与待验证假设

- 纯中文名称生成的 ID 不可读（如 `project-mxxxxxxxx`），后续如需「移山 → yishan」的拼音 ID，可引入拼音库再优化。
- 打开项目后的仪表盘等页面标题仍来自后端 `overview.title`，与作品库一致，无需额外改动。
