## 可复用经验

- const 静态数据中含 Vec 字段会触发 E0015,改为 `&'static [T]` 切片即可;带 derive(Clone) 的 struct 序列化不受影响。
- "审校必须永远可用"的降级模式(default_provider Err → local only)让功能在无密钥环境可测可演示,是建议制功能的好模式。
- 正典中已有但无 API 的字段(AestheticLayer)直接用 GET/PUT + save_project 补齐,零迁移成本。
