## 本轮落地

### P2 改写管线(commands/rewrite.rs)
- 批注 CRUD:章节级 annotations(类型:建议/批评/疑问/指令;状态机:新建→已指派→已解决;随修订历史保留),get_chapter_content 返回批注数组。
- AI 审核改写:批注/指令 + 正文 → LLM(Writer 角色)改写 → 变更说明 → 段级 LCS diff(equal/modified/added/removed)→ 前端 diff 视图逐段确认 → 应用后走 save 集成层。
- 消痕改写:anti-slop 命中片段 → LLM 定位重写(从「提示」升级为「改写」),保持语义与文风,不整章重写。
- 路由:/api/writing/annotations(+/status/delete)、/api/writing/rewrite。前端 WritingView「批注与 AI 改写」面板。

### P3 书籍蒸馏(commands/distill.rs)
- 语料摄取四格式:txt/md 直接读、epub(zip 解压 + 剥离 xhtml 标签)、pdf(lopdf 逐页提取,扫描版报错引导转 txt)。
- 均匀采样(等比取段 + 收尾补段,上限 1.2 万字/本,单段超长截断);多书混合 + 权重(入库/分析时覆盖)+ 风格强度(0.3-1.0 滑杆)。
- 7+1 维度分析(Distiller 角色):词汇/句法/修辞/叙事/节奏悬念/母题/情感基调 + 写作基因 + 禁用清单;无风格锚(版权红线内置提示词:禁止摘抄/保留原句)。
- 落盘 _config/style-recipe.json;writing/review 提示词注入配方(审校增加"风格配方对照"维度)。
- 路由:/api/distill/corpus(+/list/delete)、/analyze、/recipe(+/update)。前端:设定页「风格蒸馏」tab,FileReader→base64 上传。
- 技术点:表单 base64 需 URL 编码(+/ 会被解析成空格);router 加 DefaultBodyLimit 128MB;新依赖 zip/lopdf/base64。

### P4 级联同步(commands/cascade.rs)
- 影响分析:原稿 vs 改写稿 → LLM(Extractor)差异提取变更事实 → 本地反向检索后续章节(仅向后,上限 20 章)→ 受影响清单(章节/涉及实体/命中段落)。
- 受控级联:用户勾选 → 逐章 LLM(Writer)局部一致性修订(只改冲突段落)→ 前端逐章确认保存/全部保存;级联记录 cascade-log.json。
- 无 LLM 降级:启发式差异提取(两版共现实体名 2-4 字窗口),analyze 始终可用。
- 路由:/api/writing/cascade/analyze、/apply。前端:WritingView「级联同步」面板(handleSelect 缓存 initialContent)。

### P5 细纲化与批量写作(commands/batch.rs)
- 一键细纲化:LLM(Outliner)将大纲弧展开为带标题细纲 {chapter_no, title, summary(要点/关键事件/角色·地点·伏笔/情绪曲线/期望字数)},建议制可编辑。
- 细纲导入:按 chapter_no upsert 章节 title/summary,缺失自动创建,补齐不连续章号,落盘正典。
- 批量写作:writing.rs 抽出 pub(crate) generate_chapter 核心复用;逐章串行生成 draft,单批 ≤10 章,检查点由前端控制(每批 3 章,审阅保存后续批)。
- 路由:/api/outline/detail/generate、/import、/api/writing/batch。前端:大纲页「细纲化」区 + 笔耕页「批量写作」区。

### P6 归档压缩与操作日志(commands/archive.rs)
- extract.rs 改造:apply 函数记录结构化 AppliedFact(含 old_value/new_value),operation-log.json 升级为 {facts: [...]}(向后兼容,旧条目回滚跳过)。
- 全局回滚:逆应用最近 N 条(删新建实体/恢复角色旧值/回退伏笔状态/移除追加型功法法宝),日志同步清除。
- 归档压缩:老章节(≤ cutoff)下沉为卷摘要 _config/archive/volumes.json(章/标题/摘要/字数),保留最近 N 章明细。
- 成本档位:操作数 + Agent 绑定模型 + 蒸馏语料数 → 低/中/高档位提示。
- 路由:/api/log/operations、/rollback、/archive/compress、/list、/log/cost。前端:设定页「日志与归档」tab。
