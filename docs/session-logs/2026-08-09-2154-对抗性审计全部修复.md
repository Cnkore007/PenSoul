## 关键决策与取舍

1. 安全：项目 ID 白名单（字母/数字/`_`/`-`）在 handler 与 `ProjectStore` 双重校验；CORS 只放行 `localhost:1420`；监听改 `127.0.0.1`，端口可用 `PENSOUL_PORT` 覆盖；重复创建返回 409
2. IPC：所有 PUT 更新接口改 `Form` 解析，与前端 form body 对齐；新增 `ApiError` 统一错误码（400/404/409/500）
3. 数据链路：新增/删除统一写 ontology 后调用 `rebuild_derived()` 重建 graph/constraints/memory，废除手动双写；删除当前项目时清内存状态
4. 集成层：`save_chapter_content` 走 `Chapter::update_content`（修正修订历史旧字数/版本记录）+ `on_chapter_saved`（全量审计更新一致性评分 + 事件发布）
5. 约束引擎：5 条硬规则真实实现（角色状态倒流/性格强度、时间线倒流/第 0 章、设定重名、伏笔未埋先收、事件悬空引用），注册稳定 ID；写路径执行 `pre_edit_check` 与 `post_edit_validate`（失败回滚）
6. 状态机门控：章节与伏笔状态转换放领域层 `can_transition_to`，命令层校验，非法跳变 400
7. LLM：修复 `messages` 数组、None 字段省略、超时/重试/状态码检查；`ApiKeys` 从 `data/_config/api-keys.json` 读取；新增档案/状态/测试 API
8. 记忆检索：summary/details 真实填充、意图参与预算分配、时间/情感上下文非空；新增检索 API 与前端调试面板
9. 章节编号：新建取最大值 +1，删除不静默重排；`target_words` 默认值自洽（100 章 × 2 万字）
10. 文档：`agents.md` 索引修正并新增"当前实现状态"；`pensoul-workflow`/`pensoul-collab` 明确标注为路线图（未实现），消除文档-代码漂移
