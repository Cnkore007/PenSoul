# 会话日志：LLM 页面风格统一与远程能力

- 时间戳：2026-08-09 22:32 CST
- 目标：按用户反馈（1）LLM 页面风格与布局统一到书斋雅韵并人性化；（2）按模型名称从网络下载官方文档；（3）拉取供应商提供的模型列表

## 关键决策与取舍

1. 页面重构：设定页改为三个标签页（配置管理 / 模型档案 / 上下文检测），配置与模型用统一卡片（纸色底、墨色文字、朱砂强调、左侧色条、印章式徽章），表单改两列网格；新增空状态引导、成功提示（绿色）与加载中按钮文案
2. 官方文档下载：`llm/remote.rs` 提供 `fetch_doc`，只允许 http/https（防 SSRF），30 秒超时、5MB 上限，抓取后保存 HTML + `meta.json` 到 `data/_config/llm-docs/{model_id}.html`，同时提取标题/描述/正文预览展示在前端；真实抓取 DeepSeek 文档验证通过
3. 模型列表拉取：`list_remote_models` 请求 `{base_url}/v1/models`（OpenAI 兼容 Bearer；Anthropic 特判 `x-api-key` + `anthropic-version` 头），结果排序去重并缓存到 `data/_config/llm-models/{config_id}.json`；前端点击模型可一键建档
4. 文档提取实现：手写轻量 HTML 提取（title/meta description/去 script 与 style 的正文预览），避免引入重量级解析库；测试覆盖 URL 校验、文件名清洗、HTML 提取、模型响应解析与去重
5. 页面文案人性化：空配置引导、按钮状态（"测试中…/拉取中…/下载中…"）、操作成功即时提示、文档预览与本地路径展示
