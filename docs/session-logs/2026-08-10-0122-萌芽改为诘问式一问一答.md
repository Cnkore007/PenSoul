# 萌芽改为诘问式一问一答

## 任务目标

把萌芽对话从「自由讨论」改为「诘问式访谈」：AI 一次只问一个问题，用户回答后提炼要点并追问下一题，按固定维度覆盖故事核心，素材足够后再生成提案。

## 关键决策与取舍

- **一轮一问是硬约束**：系统提示词写入铁律——一次只问一个问题，绝不把多个问题塞进同一轮；用户回答后先一两句提炼，再抛下一个问题。
- **固定追问顺序**：高概念 → 主角 → 核心冲突 → 世界观 → 基调 → 结局与灵感；信息足够时明示「可以点生成提案」并停止提问。
- **开始诘问接口**：新增 `POST /api/sprout/start`，由 LLM 生成第一个问题；已有对话时幂等返回当前问题，避免重复提问。
- **前端体验**：空会话显示「开始诘问」按钮；输入区改为「回答当前问题」，发送按钮改为「回答」。
- 视角切换保留，作为追问侧重（结构/人物/世界观），不影响一问一答的节奏。

## 改动文件清单

- `crates/pensoul-app/src/commands/sprout.rs`：新增 `start` 命令与诘问式系统提示词（`chat_system_prompt` / `start_system_prompt`）。
- `crates/pensoul-app/src/api.rs`：注册 `/api/sprout/start` 路由。
- `src/ipc.ts`：新增 `sproutStart` 调用。
- `src/views/ConceptView.tsx`：空会话开始卡片、输入区文案、生成按钮文案调整。
- `src/App.css`：新增 `sprout-start` 样式。

## 验证结果

- `cargo test -p pensoul-domain -p pensoul-app` 全部通过；`npx tsc --noEmit` 无错误。
- 端到端实测（kimi-k3）：start 返回首问「你最想写的……那个故事，能用一句话概括它的核心冲突或核心情感吗？」；回答后 LLM 先提炼要点，再只追问一个问题（笔的代价/第一个愿望），符合诘问节奏。
- 测试项目已删除，无数据残留；后端已重启。

## 遗留事项与待验证假设

- 诘问节奏依赖模型遵循提示词，极端情况下模型仍可能一次抛多问；后续可加「回复后置校验：是否含多个问号」的兜底重试。
- 目前没有「当前问到第几题」的显式进度；如需进度条/维度指示器，可让后端在回复中返回阶段信息。
