# AI 辅助写作：基于大纲生成初稿与续写

## 任务目标

大纲（OutlineArc + 章节）已有后，让 AI 能按章写作：在笔耕页一键生成章节初稿或续写正文，产物为建议制，用户确认保存后才走集成层写入正典。

## 关键决策与取舍

- **建议制**：AI 生成结果只返回文本填入编辑器，不落盘；保存仍走 `save_chapter_content → on_chapter_saved`（修订历史 + 一致性评分 + 事件发布），不绕过集成层。
- **上下文来自正典**：`writing_context` 聚合章节所属大纲弧、前后章摘要/前文尾部、世界观规则与设定、角色卡、活跃伏笔、核心概念，交给 LLM，保证 500 万字长篇的一致性优先。
- **两种模式**：`draft` 生成整章初稿；`continue` 以编辑器已有正文为上文续写。后端对传入正文截断 3000 字，防止上下文超预算。
- **公共 LLM 辅助函数抽取**：`default_provider` / `llm_client` / `build_llm_request` 从 sprout.rs 提取到 `commands/llm.rs`，萌芽与写作共用，统一走 llm_helper。
- **先校验后调用**：章节存在性、mode 合法性在加载 LLM 配置前校验，避免无效请求触发外部调用。
- 提示词硬规则：禁止元叙述（「本章」「故事从……开始」）、只输出正文、不推翻已有设定。

## 改动文件清单

- `crates/pensoul-app/src/commands/writing.rs`（新增）：`POST /api/writing/generate`，含上下文构建与初稿/续写提示词。
- `crates/pensoul-app/src/commands/llm.rs`：抽取公共 LLM 辅助函数。
- `crates/pensoul-app/src/commands/sprout.rs`：改用公共辅助函数，删除重复实现。
- `crates/pensoul-app/src/api.rs`、`commands/mod.rs`：注册 `/api/writing/generate` 路由。
- `src/ipc.ts`：新增 `generateWriting` 调用。
- `src/views/WritingView.tsx`：新增「AI 生成初稿」「AI 续写」按钮与交互（覆盖确认、追加、保存提示）。
- `crates/pensoul-app/tests/api.rs`：新增 `writing_generate_validation` 集成测试。

## 验证结果

- `cargo test -p pensoul-app -p pensoul-domain` 全部通过；`npx tsc --noEmit` 无错误。
- 端到端实测（kimi-k3，临时项目模拟「移山」式大纲）：draft 生成约 1400 字初稿，贴合血奴/符箓/成仙设定；continue 基于已有正文自然续写约 2200 字。两次调用均不落盘。
- 实测发现初稿结尾出现「第一章，就从这片黑暗与低语开始」元叙述，已在提示词中禁止；续写未推翻已有设定也已加入硬规则。
- 测试项目已删除，后端已重启（新二进制运行中）。

## 遗留事项与待验证假设

- 当前上下文为静态聚合，未接记忆检索管线；超长作品后续可用 `pensoul-memory` 动态检索相关实体与章节。
- 单章 2000 字的目标依赖模型配合，实测约 1400 字；如需要严格字数，可后续在生成后做长度校验/重试。
- 续写只携带当前章节已有正文，跨章情节靠前后章摘要兜底，未做全量前文召回。
