# 会话日志：对抗性审计

- 时间戳：2026-08-09 20:16 CST
- 目标：对本项目做对抗性审计，找出真实缺陷而非表面问题

## 关键发现

### P0（安全与数据安全）

1. 任意目录删除：`delete_project` 用 `remove_dir_all(base_dir/projects/{project_id})`，ID 来自用户输入且无校验；沙盒实证 `../../outside-target` 可删除数据目录外目标，`..` 可删整个 `data/`
2. CORS `allow_origin(Any)` + 监听 `0.0.0.0:3001` + 创建/删除接口带 GET 副作用，任意网页可触发
3. `create_project` 同名静默覆盖已有项目
4. 前端 PUT 参数走 form body，后端全部用 `Query` 解析 URL query → 所有更新/保存接口失效（实证 400）
5. 新增角色/事件/设定只写内存图谱不落盘；伏笔不保存 → 重启丢失

### P1（核心承诺未兑现）

- 约束引擎 5 条规则全是 `TODO + pass()`；`pre_edit_check`/`post_edit_validate` 只查实体存在；写路径从不调用
- 记忆检索从未被调用，summary/details 恒空，意图识别结果被丢弃
- `LlmClient::complete` 丢弃 `request.messages`、`messages` 传对象而非数组、无超时/重试/状态码检查；无任何调用方
- 事件总线定义了但从未实例化；`on_chapter_saved` 不存在；`Chapter::update_content`（修订历史）是死代码
- ontology 与 graph 手动双写（`let _ = ontology` 绕借用），constraints/memory 是打开项目时的一次性快照
- 影响预测依赖关系，但没有任何 API 能添加关系 → 恒空
- 所有 handler 返回 `Result<String, String>`，错误全部 HTTP 200，前端 catch 失效（实证）
- 章节删除后编号不重排、新建用 `len+1` 可能重复；章节/伏笔状态任意跳变；`actual_payoff` 无法设置
- `ProjectSettings` 默认 200 万字与 `recalc` 20 万字矛盾

- `target/` 3GB、`dist/` 遗留、`src/views/` 空目录、`public/` 空（favicon 404）
- `App.tsx` 1185 行超限；`BlueprintView` 直接 fetch 绕过 ipc 唯一入口
