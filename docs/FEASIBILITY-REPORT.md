## 四、总体评估

### 全部已验证的核心架构（可进入开发）

1. **Harness 确定性流程引擎** — 理论验证通过，可直接用 Rust 实现
2. **CDA 影响图** — 性能验证通过，500 万字规模无压力
3. **四层记忆系统** — 效果优先，全量注入验证通过
4. **工具白名单** — 硬性隔离机制可行
5. **门控三模式** — 自动/人工/条件放行逻辑正确
6. **崩溃恢复（WAL）** — 状态持久化和重放机制可行
7. **并发控制** — 乐观锁+操作队列验证通过
8. **双通道通信** — signal/report分离验证通过
9. **插件系统** — YAML声明式工作流验证通过
10. **增量一致性检查** — 分层策略验证通过
11. **数据导入** — 章节自动检测验证通过
12. **LLM模型路由器** — 效果优先降级验证通过

### 风险评估

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 实际 LLM 生成质量不稳定 | 高 | 高 | 条件门控自动重试 + 人工兜底 |
| 影响图在真实文本上的召回率 | 中 | 中 | 用真实小说数据做 A/B 测试 |
| 500 万字时的磁盘 I/O | 低 | 中 | LanceDB 增量索引 + 分页加载 |
| 跨平台 UI 一致性 | 低 | 低 | Tauri 2 统一 WebView |
