## 背景与目标

PenSoul 2.0 的第一性原理重设计（见 `docs/REDESIGN.md`）：**让引擎管流程，让模型管创作**。

三个根本转变：

1. **流程控制 → 约束边界**：引擎定义"不能做什么"，而非"必须按什么顺序做"
2. **记忆存储 → 信息检索**：系统预测用户需要什么信息，而非被动等待查询
3. **事后检测 → 事前预防**：在修改时预测影响，在创作时检查一致性

知识库化重构的总体目标：以 `NovelOntology` 为唯一正典，将图谱、约束引擎、记忆管线作为派生状态，
写操作统一走 `rebuild_derived` 重建；AI 产物默认**建议制**，用户确认后才写入正典。

## P0b · Agent 体系

- 五角色：writer（写作）/ reviewer（审校）/ extractor（事实提取）/ outliner（细纲）/ distiller（蒸馏）
- 每个角色可绑定一个 LLM 配置（`llm_config_id`），**None = 回退全局默认**（向后兼容）
- 配置存 `data/_config/agent-config.json`（全局，预留 project_overrides 供作品级覆盖）
- writing/review 等模块统一经 `agent::resolve(role)` 解析模型
- 实现：`crates/pensoul-app/src/commands/agent.rs`（注册表 + list/update API）

## P0 · 档案化

- 人物档案扩展字段：外貌 / 衣着 / 功法 / 境界 / 法宝
- 新增组织档案实体（`Entity::Organization`，编译器强制所有 match 补全：评估器/记忆评分/摘要/描述）
- 图谱知识库页重构：类型 tab（人物/组织/设定/事件/伏笔/规则）+ 搜索 + 详情编辑
- 侧边栏合并：删除蓝图/人物/世界视图（能力并入图谱与大纲），笔耕移到大纲下

## P1 · 事实提取管线

- 保存章节后自动触发（前端非阻塞调用，不拖慢保存）
- LLM（Extractor 角色）提取结构化 Fact 包 → 应用（同名跳过 / 追加去重 / 伏笔推进）
- 冲突告警（`full_audit` 硬约束）→ 操作日志（`data/_config/operation-log.json`，最近 500 条）
- Fact 应用是真实写正典 + `rebuild_derived`，绝不静默丢弃
- 解析宽容归一化：统一 `parse_llm_json`，同时接受 `{"facts":[...]}` 与裸数组
- 提示词注入与本章相关的档案实体清单；已建档角色 `character_update`，未建档 `new_character`
- 结构化输出（`json_mode=true`）必须给 `structured_output_tokens` 预算（≥4096，长文本 ≥8192）

## P2 · 改写管线

- 批注 CRUD：章节级 annotations（建议/批评/疑问/指令），状态机：新建 → 已指派 → 已解决，随修订历史保留
- AI 审核改写：批注/指令 + 正文 → LLM（Writer）改写 → 变更说明 → 段级 LCS diff（equal/modified/added/removed）→ 前端逐段确认 → 应用走 save 集成层
- 消痕改写：anti-slop 命中片段 → LLM 定位重写（保持语义与文风，不整章重写）

## P3 · 书籍蒸馏

- 语料摄取四格式：txt / md / epub（zip 解压 + 剥离 xhtml 标签）/ pdf（lopdf 逐页提取，扫描版报错引导转 txt）
- 均匀采样（等比取段 + 收尾补段，上限 1.2 万字/本）；多书混合 + 权重 + 风格强度滑杆（0.3–1.0）
- 7+1 维分析（Distiller）：词汇/句法/修辞/叙事/节奏悬念/母题/情感基调 + 写作基因 + 禁用清单
- **版权红线**：无风格锚（禁止摘抄/保留原句）
- 落盘 `data/_config/style-recipe.json`，注入 writing/review 提示词；按项目隔离

## P4 · 级联同步

- 影响分析：原稿 vs 改写稿 → LLM（Extractor）差异提取变更事实 → 本地反向检索后续章节（**仅向后**，上限 20 章）→ 受影响清单
- 受控级联：用户勾选 → 逐章 LLM（Writer）局部一致性修订 → 前端逐章确认/全部保存 → `cascade-log.json`
- 无 LLM 降级：启发式差异提取（共现实体名 2–4 字窗口），analyze 始终可用
- 向前同步默认禁止（设计护栏）

## P5 · 细纲化与批量写作

- 一键细纲化：LLM（Outliner）将大纲弧展开为带标题细纲（章号/标题/摘要：要点/关键事件/角色·地点·伏笔/情绪曲线/期望字数），建议制可编辑
- 细纲生成分块：每 12 章一批，注入全书上下文（核心概念/世界观/人物/伏笔/风格笔记），只接受请求章号区间，返回 `missing_chapters`
- 细纲导入：按 chapter_no upsert 章标题/摘要，缺失自动创建，补齐不连续章号；章号上限 = 当前最大 +500（防 DoS），回写 `expanded_until`
- 批量写作：复用 `generate_chapter` 核心，逐章串行生成；**硬门控**：仅「已有细纲且正文为空」的章节可进入批量；单批 ≤10 章，前端检查点制（每批 3 章，审阅保存后续批）
- 记忆检索 + 硬约束 + 技巧注入 + 消痕检测注入写作上下文

## P6 · 归档压缩与操作日志

- 结构化操作日志：`operation-log.json` 升级为 `{facts: [...]}`（含 old_value/new_value，向后兼容）
- 全局回滚：逆应用最近 N 条（≤100；删新建实体/恢复角色旧值/回退伏笔状态/移除追加型功法法宝），日志同步清除；日志写失败显式 `log_warning`
- 归档压缩：老章节（≤ cutoff）下沉为卷摘要 `data/_config/archive/volumes.json`，保留最近 N 章明细
- 成本报告：操作数 + Agent 绑定模型 + 蒸馏语料数 → 低/中/高档位

## 落地后的优化（2026-08-14）

- 事实提取修复：JSON 形状统一 + 思考型模型截断（`structured_output_tokens` 兜底），实测提取成功并落档案
- 仪表盘创作流水线：萌芽定盘/人物档案/世界观/大纲/细纲/批量写作/审校发布 7 阶段 readiness 与下一步动作
- 写作上下文相关性优先：先纳入本章细纲、所属脉络、相邻章节实际提到的实体，再按档案顺序补足

## 遗留事项（后续阶段候选）

- 细纲全本生成按弧顺序串行分块，无流式进度/取消（建议增加任务进度事件或前端轮询）
- 事实提取重复保存会重复记录操作日志（可加 diff 后仅记录真实变化）
- 归档压缩为"卷摘要下沉 + 日志可回溯"轻量版；完整版需档案模型改造（图谱/约束不受影响）
- 事件总线 `on_chapter_saved` 当前无订阅者；`pensoul-workflow` / `pensoul-collab` / `pensoul-orchestration` 属 REDESIGN 路线图，未实现
