# 《雪中悍刀行》（烽火戏诸侯） 写作技能包

> 蒸馏时间：2026-08-01 · 模式：知识蒸馏 · 共 5 张卡

- **文风 DNA**（`style/SKILL.md`）：适合写对话密集、多人物同场或武戏爆点的章节时绑定：落笔前给人物分语域，用长短句两极控节奏，爆点处推近叙事距离。写说明性、冷硬极简或需刻意压低存在感的章节时不绑。
- **叙事结构**（`structure/SKILL.md`）：写长篇多线故事、需要在细纲阶段规划双线换挡、延迟引爆与伏笔回收时绑定，用于 outline_expand。不适合短篇、单线推进、或不打算管理跨章线索的作品。
- **人物塑造**（`character/SKILL.md`）：用于细纲展开与章节写作中的角色塑造：登场前的侧面赋魅、细节立人、武力与心性绑定的成长弧线。需要让新角色快速立起来、避免配角写丢、让升级具备情感重量时绑定。不适用于纯快节奏爽文升级流、角色工具化为主的短篇。
- **冲突与张力**（`tension/SKILL.md`）：细纲展开需设计「延迟释放」的高潮节奏、章节写作需制造认知落差或把武戏代价前置时绑定本卡；权谋、成长、热血战斗类章节尤其适用。不绑：即时释放型短节奏、无实质代价的日常段落、需要持续安全感的治愈向叙事。
- **类型范式**（`genre/SKILL.md`）：构建玄幻/武侠混血、双轨叙事（庙堂与江湖），或以“选择”而非“胜负”定义高潮时绑定；帮你立类型魂、管理双读者期待、设计不可逆代价节点。单一线索、轻松喜剧、短篇快节奏或读者有强“主角必胜”预期时不绑定。

适用环节说明：`outline_expand` 细纲展开 / `chapter_writing` 章节写作 / `review` 一致性审查。
