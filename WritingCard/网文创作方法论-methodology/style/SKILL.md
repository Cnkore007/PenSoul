# 网文创作方法论 · 文风技法卡

## R · 手法出处
综合主流网文写作经验与 LLM 写作 skill 的去 AI 味实践：AI 文本质量低的主因是表达安全、中性、可预测，缺乏具体性与个人性。

## I · 技法骨架
- 删套话：不禁、仿佛、映入眼帘、心中暗道、嘴角微扬、脸色一变、此时此刻等一律不写，换成具体动作或直接删掉。
- 控弱化副词：微微/淡淡/缓缓/轻轻/悄然/默默，每千字不超过 3 个。
- 不用排比三连（三个词一组堆「全面感」），不用「与此同时/从而/于是乎/诚然」等书面连接词。
- 情绪不许直说：「他很担忧」改为「他的后背出了一层冷汗」；「她很聪明」改为写她做了什么具体的聪明事。
- 长短句交替，段落不超过五行；对话优先于叙述，行动优先于形容。

## A1 · 案例
- 原句「他不禁感到一阵心悸，仿佛有什么大事要发生」→「他的手抖了一下。门外有人敲门。」
- 原句「她嘴角微扬，勾起一抹弧度」→「她笑了。」

## A2 · 适用场景
- 写正文时作为语言检查清单；审查时按此扫描扣分项。
- 不适用于刻意追求华丽辞藻的古典文风、译文腔、或需要长句铺陈的独白段落。

## E · 执行步骤
1. 动笔前默读一遍本卡铁律，正文按「动作 + 对话 + 短段落」推进。
2. 写完每千字回扫一遍：弱化副词超 3 个就删到 3 个以内。
3. 逐个查套话词表，命中即替换为具体感知或删除。
4. 对情绪场景自问「读者能看见画面吗」——看不见就补一个动作或物件细节。

## B · 边界
- 过度执行会让文字干瘪，保留 10% 的修辞自由度；本卡为通用经验总结，非逐字引用某作品。
