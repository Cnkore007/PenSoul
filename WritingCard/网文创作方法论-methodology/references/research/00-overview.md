# 网文创作方法论 调研存档

> 时间：2026-08-02 · 来源：公开网文写作经验 + GitHub 写作 skill（novel-creator-skill / ai-fiction-writer 等）调研

## 调研要点
- 黄金三章：第一章立刻出事（核心事件）、第二章金手指与期待、第三章首个爽点；三章未爽基本作废。
- 爽点前置、对话优先、行动优先于形容。
- 长篇一致性：一次性生成跨度越大质量越差，解法是「Beat Sheet 生成 → 扩写 → 章节合成 → 门禁」的多步流水线。
- 反向刹车：非终局章节禁止解决主线核心冲突，每章必须新增未解决的次要问题，章末留钩子。
- 事件冷却：冲突爽点/羁绊/势力经营/风土人情/危机升级各有冷却期，防止剧情模式化。
- 去 AI 味七类模式：AI 高频词、弱化副词、意义膨胀、通用套话、论文结构、正式语体、排比三连。
- 七维加权审稿：单一总分易掩盖单项硬伤，按维度给分并对照节拍表检查执行度。
