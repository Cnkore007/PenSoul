# 网文创作方法论 · 审查技法卡

## R · 手法出处
多维度加权审稿来自写作 skill 的「编辑团队分工」与「质量门禁」实践：单一总分容易被高分掩盖单项硬伤。

## I · 技法骨架
- 七维权重：卖点兑现 20、开场钩子 10、情绪曲线与爽点 20、场景与节奏 10、断章钩子 15、人物与设定一致性 15、文笔与反 AI 味 10。
- 对照章前策划节拍表检查执行度：明显偏离计入问题清单并扣分。
- 前 3 章硬门控：开场钩子（hook）与爽点（payoff）两个 0-10 子分数必须 ≥ 8，任一不达标即使总分合格也拦截重写。
- 诚实给分：不得因总分高而虚高子分数；问题清单要给到可修改的具体位置。

## A1 · 案例
- 总分 88 但开场 300 字是背景说明 → hook 给 5 分，前 3 章按门控拦截并要求重写开篇。

## A2 · 适用场景
- 章节审查环节使用；全章一致性检查可只取第 ⑥ 维。
- 快速试稿场景可压缩为三维（卖点/一致性/文笔）。

## E · 执行步骤
1. 逐维打分（各维先给 0-10 原始分，再按权重折算）。
2. 汇总总分，输出 score 与 issues。
3. 前 3 章额外输出 hook/payoff 子分数，任一 < 8 直接判拦截。
4. 审查报告先给结论，再列问题清单（位置 + 原因 + 建议）。

## B · 边界
- 评分是信号不是判决，允许作者以人工门控覆盖；子分数缺失时黄金三章门控自动退化为总分门控。
