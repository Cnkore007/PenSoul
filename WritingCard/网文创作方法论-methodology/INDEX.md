# 网文创作方法论 写作技能包

> 蒸馏时间：2026-08-02 · 模式：方法论内建 · 共 6 张卡

- **文风 DNA**（`style/SKILL.md`）：反 AI 味语言铁律，删套话、控弱化副词、具体细节代替情绪直说。
- **叙事结构**（`structure/SKILL.md`）：章前策划节拍表结构、压抑-释放情绪曲线、断章钩子三型。
- **人物塑造**（`character/SKILL.md`）：动机先行、金手指按章定制、对话立人设、状态跟踪。
- **冲突与张力**（`tension/SKILL.md`）：冲突升级、事件冷却、反向刹车、每章新问题。
- **类型范式**（`genre/SKILL.md`）：开篇黄金三章（核心事件 → 金手指 → 首个爽点）。
- **审查维度**（`review/SKILL.md`）：七维加权评分与前三章钩子/爽点硬门控。

适用环节说明：`outline_expand` 细纲展开 / `chapter_planning` 章前策划 / `chapter_writing` 章节写作 / `review` 一致性审查。
