# PenSoul · 方法论蒸馏术

> 把一段「写作方法论」（文章、经验贴、讲稿、AI 对话提炼等）切成可绑定工作流环节的写作技能卡。

## 核心理念

提炼「可执行的方法」，不是「观点总结」。一段方法论只有落到「什么场景下怎么做、做完怎么判断完成」才配成为技能卡。

产物红线：
- 不写泛泛的道理与态度口号（「要坚持」「要有耐心」一律丢弃）；
- 不抄原文长段落，用自己的话重写成可执行步骤；
- 每条技法必须有明确的适用场景与失效边界；
- 每维取 1-3 个技法，宁少勿多；来源信息不足时标注置信度。

## 六维度

- style 文风：语言规则、句式节奏、去套话/去 AI 味的检查清单；
- structure 结构：章节/场景编排、节拍表、钩子与情绪曲线；
- character 人物：动机、对话、人物状态、金手指与限制；
- tension 张力：冲突升级、爽点、事件冷却、断章；
- genre 类型：题材惯例、读者期待管理、开篇节奏；
- review 审查：评分维度、门禁标准、问题清单格式。

## 卡片六段（RIA++）

```
## R · 手法出处   方法原文里这条技法的典型位置
## I · 技法骨架   自己的话重写 5-15 行，没读过原文的人能看懂
## A1 · 原文案例  1-3 个：原文怎么说的 → 怎么用 → 效果
## A2 · 适用场景  3-5 个可识别场景 + 何时不绑这张卡
## E · 执行步骤   1-2-3 步骤，每步有可判断的完成标准
## B · 边界       什么题材/章节不该用 + 来源局限 + 置信度声明
```

## 三重验证

每个候选技法必须过三重验证，全过才「成立」：
- V1 跨方法复现：方法原文里至少 2 个独立位置有体现；
- V2 生成力：能指导一段原文没写到的具体写作动作；
- V3 独特性：不是所有作者都会这样做的常识。

判定：三重全过 = 成立；过 1-2 重 = 降级为附注；0 重 = 丢弃。

## 执行流程

1. **方法论骨架**：通读用户提供的方法论文本，提炼 3-5 个支柱 + 批判（什么不该学）+ 维度预判。
2. **提取与验证**：逐维提取候选技法并做三重验证。
3. **逐维构卡**：只保留「成立」的技法，按 RIA++ 六段构卡。
4. **交付落盘**：写入 `WritingCard/<标题>-methodology/`，含 package.json / INDEX.md / references/research/ 存档。
