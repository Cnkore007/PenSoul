# PenSoul 创作全流程说明书

> 从 0 到作品完成，这是一份完整的创作指南。

---

## 一、核心概念

PenSoul 将一部小说的创作视为**四层本体**的协同构建：

| 层 | 名称 | 内容 | 示例 |
|----|------|------|------|
| 第1层 | 世界观 (World) | 地点、时间线、设定规则 | 魔法大陆、编年史、力量体系 |
| 第2层 | 人物志 (Character) | 角色、性格特质、关系网络 | 主角、配角、敌友关系 |
| 第3层 | 叙事层 (Narrative) | 卷、章、伏笔、情节结构 | 三卷十五章节、悬念布局 |
| 第4层 | 智能体层 (Agent) | 创作流程编排、AI 协同 | 工作流模板、造化工坊 |

**核心哲学**：AI 无权跳步，一切由引擎驱动。人在回路中掌控方向。

## 二、从零开始的创作流程

### 第一步：创建项目

1. 打开 PenSoul，进入**作品库**（首页）
2. 点击「新建作品」，输入作品名称和描述
3. 进入项目**仪表盘**，看到完整的创作空间

### 第二步：构建世界观（第1层）

进入**世界观**模块，分三个子模块构建：

- **地点**：记录故事发生的地理位置、场景
  - 每条地点包含名称和描述
  - 例如：迷雾森林、王都、地下城
- **时间线**：标注故事中的重要历史事件
  - 格式灵活，如「第一年春」、「纪元年」等
  - 事件按时间顺序排列
- **设定规则**：描述世界的底层逻辑
  - 魔法体系、科技水平、社会制度等
  - 确保设定前后一致

> **提示**：如果一时没有灵感，点击下方的「灵感」面板，AI 会基于已有设定生成创意建议。灵感面板支持多次刷新「换一批」。

### 第三步：创造角色（第2层）

进入**人物志**模块：

1. 点击「新建角色」，填写：
   - 角色名
   - 性格特征（用逗号分隔多个特征）
   - 当前心境（可选）
2. 角色卡片会按网格排列，一目了然
3. 可在后续创作中随时增删改

> **灵感参考**：点击灵感面板获取角色创作建议，如性格反差、隐藏秘密、镜像角色等经典手法。

### 第四步：搭建大纲（第3层）

进入**大纲**模块，这是故事的骨架：

1. **新建卷** — 作品的一大部分
   - 例如：第一卷·迷雾初现、第二卷·暗流涌动
2. **在每个卷中添加章节**
   - 每章设定标题
   - 后续在笔耕模块填充正文
3. 大纲页面自动统计总章数和字数

> **创作规划**：在仪表盘的「创作规划」区域，可以设定：
> - 目标总章数
> - 目标总字数
> - 每章目标字数
> - 预计卷数
> 
> 系统自动追踪进度百分比，用进度条直观展示。

### 第五步：笔耕不辍（第3层 - 正文）

进入**笔耕**模块：

1. 从左侧章节导航选择要写的章节
2. 使用富文本编辑器（TipTap）进行写作
3. 写作时自动统计字数
4. 点击「保存」持久化内容
5. 章节状态自动流转：草稿 → 审阅中 → 已审阅 → 润色中 → 已发布

> **灵感参考**：写作时右侧的灵感面板会根据当前章节上下文，提供叙事视角、场景描写、对话设计等方面的创意建议。

### 第六步：配置工作流（第4层）

进入**工作流**模块，这是自动化写作的关键：

1. 选择工作流模板
   - **标准小说工作流**：5 个阶段（大纲 → 写作 → 审查 → 润色 → 发布）
   - **快速创作工作流**：3 个阶段（精简流程）
2. 可以自定义每个阶段的工具白名单、门控规则等

### 第七步：启动造化工坊（自动写作）

进入**造化工坊**模块：

1. 确保已配置工作流模板
2. 配置 LLM 模型（在「模型设置」中添加供应商和 API Key）
3. 点击「启动」，AI Agent 按照工作流阶段自动推进创作
4. 每个阶段完成后经过门控判定：
   - **Auto**：自动进入下一阶段
   - **Manual**：需要人工确认
   - **Conditional**：根据评分判定（如一致性评分 >= 80）
5. 门控失败会自动回退，支持重试机制

## 三、模块功能详解

### 审校（一致性检查）

自动检测作品中前后不一致的地方：

- 角色属性变化（如名字、外貌、位置）
- 设定规则违反
- 时间线冲突
- 伏笔未回收

### 墨韵（文风分析）

分析作品的：

- 平均句长
- 词汇丰富度
- 对话比例
- 节奏评分
- AI 模式得分（检测 AI 写作痕迹）

### 模型设置

管理 LLM 供应商和模型：

1. **供应商**：支持 OpenAI、Anthropic、DeepSeek、Moonshot、TokenHub、本地 Ollama 等
2. 每个供应商可以：
   - 配置 API 地址
   - 配置 API Key
   - 测试连接
   - 自动获取模型列表
3. **模型列表**：按供应商分组显示
   - 每个模型可以单独测试连通性
   - 可以启用/禁用某个模型
   - 显示质量评分、延迟等指标

### 插件系统

支持 YAML/JSON 声明式插件：

- 自定义工作流阶段
- 扩展创作工具
- 配置自动化规则

## 四、进阶使用

### 确定性流程引擎

PenSoul 内置的 Harness 引擎确保创作流程的**确定性**：

- **WAL（Write-Ahead Log）**：每次状态变更先写日志再执行，保证崩溃可恢复
- **滚动备忘录**：跨阶段注入核心创作方向，让 AI 始终记住核心设定
- **工具白名单**：每个阶段严格控制 AI 可以使用的工具
- **门控系统**：三模式判定（自动/人工/条件），确保质量

### 数据安全

- API Key 在序列化时自动跳过（`#[serde(skip_serializing)]`）
- 路径操作包含目录遍历防护
- WAL 使用 blake3 校验和防篡改
- 并发控制使用乐观锁，防止版本冲突

### 快捷键与效率

| 操作 | 说明 |
|------|------|
| 灵感面板 | 在各创作模块底部，点击「灵感」展开 |
| 换一批 | 点击灵感面板底部的刷新按钮重新生成 |
| 创作规划 | 在仪表盘底部编辑目标数值 |

## 五、创作建议

### 推荐创作顺序

```
世界观 → 角色 → 大纲 → 正文 → 工作流 → 自动写作 → 审校润色
```

### 何时使用灵感面板

- **写不出角色时**：看人物志灵感面板
- **设定卡壳时**：看世界观灵感面板
- **不知如何推进时**：看大纲灵感面板
- **章节写不动时**：看笔耕灵感面板

### 何时使用自动写作

- 有了完整的大纲和设定后
- 需要快速生成初稿
- 处理重复性的过渡章节
- 配合人工润色，效率最高
